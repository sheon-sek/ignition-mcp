# ignition-runtime-bundle

Designer Project source for the `ignition-runtime` server provided by the Ignition Official MCP Module.

This Phase 0 source is a **disabled technical scaffold**. `NATIVE_BINDING_PENDING` is a hard gate: a production-compatible Bundle cannot be built or marked `SUPPORTED` until a real Gateway and exact MCP Module build prove Tool `outputSchema`, successful `structuredContent`, and failure `isError` behavior.
